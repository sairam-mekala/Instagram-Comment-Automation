Privacy Policy

Last updated: August 12, 2026

This Privacy Policy explains how Comment Automation handles information received through the Instagram API.

1. What This App Does

Comment Automation is a personal automation application used to monitor comments on Instagram content and perform predefined automated actions, such as replying to comments and sending private replies based on specific comment keywords.

2. Information We Receive

When Instagram sends information to the application, it may include:

  • Instagram username
  • Instagram user ID
  • Comment text
  • Comment ID
  • Instagram media ID
  • Information associated with the Instagram comment event

3. How Information Is Used

The information is used only to operate the Instagram comment automation, including identifying comments, checking predefined keywords, and performing automated public replies or private replies.

4. Data Sharing

Comment Automation does not sell, rent, or otherwise share Instagram user information with third parties for advertising or marketing purposes. Information may be transmitted through Meta's Instagram API as necessary to provide the requested Instagram functionality.

5. Data Storage and Retention

The application is designed to process Instagram information for the purpose of performing the requested automation. Information is not intentionally retained longer than necessary for the operation of the automation.

6. Data Security

Reasonable measures are used to protect application credentials and information processed by the application. Access tokens and other sensitive credentials are intended to be stored securely and are not publicly shared.

7. User Data Deletion

If you would like to request deletion of information processed by this application, please contact the application owner using the email address below. Requests will be reviewed and applicable data will be deleted where required.
